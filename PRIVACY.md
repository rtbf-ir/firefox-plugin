# Privacy policy

The extension reads the address of the active tab only after the user opens it, compares its hostname with the public RTBF directory, and shows the deletion difficulty and link when available.

It does not collect browsing history, credentials, form content, cookies, personal identifiers, or analytics. It does not transmit the active URL. The public directory and its refresh time are cached locally for up to 24 hours; uninstalling the extension or clearing its local storage removes this cache.

The only network request is for `https://rtbf.ir/data/data.json`.

Contact: info [at] rtbf [dot] ir
